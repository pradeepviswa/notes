# cData Migration and Resilience
data migration from on-prem to cloud

### Basics of Data Migratration

- moving data
- it is not always about copy paste
- it involves data cleaning
- dta transportation
- data validation


### types
- storage migration
  - moving data between storage systems example on pre to cloud, legacy h/w to SSDs
- Data base
  - migrate from MSSQL to MySQL
- Application or data replication
  - synchronization or replication or data between two storage
