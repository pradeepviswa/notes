# Virtual Machine Scale Set
> This is used to autoscale VMs in app pool.
> It is used with Load balance

### scaling
#### Vertical scaling
> Not recomended as it incldues hardware increase which may create problem
- applicaiton may not suppor tnew h/w configuraiton
- OS may not support increased CPU/RAM config

#### Horizontal Scaling
This is preferred. Number on VMs increases.

#### scaling terms
#### Horizontal
Horizontal +++++ `Scale Out`
Horizontal ------ `Scale In`
#### Vertical
Vertical  +++++ `scale up`
vertical scaling ------ `scale down`
